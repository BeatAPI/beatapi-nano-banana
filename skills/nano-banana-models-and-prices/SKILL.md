# Nano Banana Models and Prices

Choose a model

Work only with this family: nano-banana-2, nano-banana-2-lite, nano-banana-2.1, nano-banana, nano-banana-pro. Discover newly available family members before recommending a model. Include all supported models rather than silently choosing a different one.

Match the request

Read each model's current BeatAPI input contract. Compare only supported resolutions, quality options and reference inputs. Tell the user clearly when an option is unavailable.

Explain the cost

Use current prices at https://beatapi.io/pricing and the model contract. State the model, resolution, quality, billing unit and applicable reference inputs. A starting price is an example for its stated specification, not a quote for every request. Do not extrapolate video or reference input fees without a documented billing basis.

Let the user choose

Recommend one suitable option and explain the tradeoff in plain language. Never switch the model, quality or specification without the user's agreement. This skill only researches options and prices. It does not start a paid task.

The complete dated family catalogue is in MODELS.md. Runtime discovery must remain restricted to this family.
